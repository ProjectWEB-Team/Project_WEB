  <name>Task 3 (TASK-003): Cấu hình Khung Dual SecurityFilterChain & BCrypt</name>
  <files>src/main/java/vn/iotstar/config/SecurityConfig.java</files>
  <read_first>docs/LECTURE_STANDARDS.md, docs/rule.md, .planning/STATE.md</read_first>
  <action>
    Tạo `src/main/java/vn/iotstar/config/SecurityConfig.java`:
    - Annotation: `@Configuration`, `@EnableWebSecurity`.
    - Bean PasswordEncoder: `@Bean public PasswordEncoder passwordEncoder() { return new BCryptPasswordEncoder(); }`.
    - Filter Chain 1 (@Order(1)) - Dành riêng cho REST API:
      * Matcher: `/api/**`
      * Session: `SessionCreationPolicy.STATELESS`
      * CSRF: disable (Stateless REST)
      * Authorization: permitAll cho `/api/tracking/**`, `/api/calculator/**`; authenticated cho các API tác nghiệp khác.
    - Filter Chain 2 (@Order(2)) - Dành cho Web SSR JSP:
      * Matcher: `/**`
      * Session: `SessionCreationPolicy.IF_REQUIRED`
      * CSRF: enable với CookieCsrfTokenRepository hoặc default
      * Form Login:
        - `loginPage("/login")`
        - `loginProcessingUrl("/login")`
        - `defaultSuccessUrl("/", true)`
        - `failureUrl("/login?error=true")`
        - `permitAll()`
      * Logout:
        - `logoutUrl("/logout")`
        - `logoutSuccessUrl("/login?logout=true")`
        - `deleteCookies("JSESSIONID")`
        - `invalidateHttpSession(true)`
      * Public Endpoints: permitAll cho `/`, `/home`, `/tracking/**`, `/calculator/**`, `/auth/**`, `/login`, `/register`, `/assets/**`, `/webjars/**`, `/ws/**`.
  </action>
  <verify>
    Chạy `mvn test-compile` kiểm tra cấu hình SecurityConfig biên dịch hợp lệ không lỗi cú pháp.
  </verify>
  <acceptance_criteria>
    - `SecurityConfig.java` khai báo đủ 2 `@Bean SecurityFilterChain` với `@Order(1)` và `@Order(2)`.
    - PasswordEncoder sử dụng `BCryptPasswordEncoder`.
    - `mvn test-compile` hoàn tất thành công.
  </acceptance_criteria>
  <done>Khung bảo mật kép cho cả Web JSP và REST API sẵn sàng.</done>

<threat_model>
- ASVS Level: L1 (Foundation)
- Threat 1: Lộ thông tin nhạy cảm qua lỗi Stack Trace khi CSDL chưa bật. Mitigated: Cấu hình `server.error.include-stacktrace=never`.
- Threat 2: Đánh cắp phiên qua tấn công XSS. Mitigated: Cấu hình cookie session `http-only=true` và `same-site=lax`.

- Threat 4: Mật khẩu plaintext. Mitigated: Khởi tạo bean `BCryptPasswordEncoder` bắt buộc cho tất cả luồng xác thực.
</threat_model>
