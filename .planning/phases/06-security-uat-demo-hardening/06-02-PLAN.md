## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated user to user-owned resources | Any signed-in role reaches /user/** routes; ownership is decided only in the service layer. |
| manager/admin session to finance data | Hub-scoped finance actions cross hub boundaries (subtree versus sibling hubs). |
| shipper session to delivery and COD actions | Assignment, hub and location decide which parcel a shipper may touch. |
