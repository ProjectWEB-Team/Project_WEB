## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/session to web chain | Untrusted HTTP requests with a session cookie cross into role-restricted JSP routes. |
| bearer token to API chain | Untrusted JWT-bearing requests cross into /api/** capabilities. |
| anonymous internet to public routes | Unauthenticated callers reach registration, tracking and auth endpoints. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Elevation of Privilege | SecurityConfig web chain prefix rules | high | mitigate | PermissionMatrixRouteTest asserts 403 for every non-allowed role on every controller route and the completeness guard fails when a route has no row. |
| T-06-02 | Tampering | State-changing web POST routes | high | mitigate | Missing-CSRF test asserts 403 for the authorized role on every POST row; API chain CSRF-disabled behavior is asserted separately as the intended stateless design (D-03). |
| T-06-03 | Spoofing | Anonymous access to protected routes and APIs | high | mitigate | Anonymous cells assert redirect to login (web) and 401 JSON (API) for every non-public row. |
| T-06-04 | Information Disclosure | Unlisted paths | medium | mitigate | Default-deny rows assert anonymous callers never reach an unlisted web or API path. |
| T-06-05 | Tampering | Regression introduced by a SecurityConfig fix | medium | mitigate | Any SecurityConfig change is followed by the full *SecurityTest run in the same task; no fix is accepted without the matrix green. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager install and no pom.xml change in this plan, so the package-legitimacy gate does not apply. |
</threat_model>
