<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser session to STOMP endpoint | Untrusted client frames (CONNECT, SUBSCRIBE, SEND) cross the client inbound channel. |
| server publisher to user queues | Server-chosen recipients receive private events; a wrong recipient is a data leak. |
| cross-origin page to WebSocket handshake | A foreign origin must not open an authenticated socket. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11 | Information Disclosure | Stomp*Publisher and OperationalRealtimePublisher recipient selection | high | mitigate | Per-user verification with verifyNoMoreInteractions asserts exactly the intended recipients and no unrelated or inactive user for every event type. |
| T-06-12 | Elevation of Privilege | AuthenticatedShipmentStompInterceptor | high | mitigate | Command x destination x principal matrix denies unauthenticated frames, every client SEND, and every subscription except the three private user destinations. |
| T-06-13 | Information Disclosure | Event payload DTOs | medium | mitigate | Record-component and serialized-key allow-list assertions for shipment, notification and operational payloads. |
| T-06-14 | Repudiation | Emission on rollback or before commit | medium | mitigate | Synchronization and real Spring listener tests assert no template interaction before commit or after rollback. |
| T-06-15 | Spoofing | Cross-site WebSocket hijacking via permissive origin | high | mitigate | registerStompEndpoints test asserts the endpoint registration receives no allowed-origin call, preserving the same-origin default; handshake still requires an authenticated session (existing WebSocketEndpointSecurityTest). |
| T-06-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager install and no pom.xml change in this plan, so the package-legitimacy gate does not apply. |
</threat_model>
