<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| JSP form → ShipmentController | Sender/receiver data and any hidden identifiers are untrusted input. |
| controller → ShipmentService | The service must bind the request to AuthenticatedActor, not a request actor ID. |
| JPA → SQL Server | Entity values are persisted against canonical constraints and must map to the approved schema. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-04 | E | Shipment detail service | high | mitigate | Service-boundary ownership check uses AuthenticatedActor and returns forbidden for non-owners. |
| T-01-05 | T | Shipment status/event persistence | high | mitigate | Fixed 13-value enum and separate event type prevent operational activity from becoming state. |
| T-01-06 | I | JSP/detail DTO | medium | mitigate | Bean validation, escaped JSP output, and DTO responses prevent raw entity/credential exposure. |
| T-01-07 | R | Shipment events | medium | mitigate | Creation event records actor and timestamp in the same service transaction as the shipment. |
| T-01-SC | Tampering | SQL Server verification | high | mitigate | SQL Server profile reads secrets only from environment and integration testing verifies the real canonical DBMS. |
</threat_model>
