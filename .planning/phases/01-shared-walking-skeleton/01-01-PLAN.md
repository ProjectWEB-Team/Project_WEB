<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser/API client → security filters | Credentials, CSRF tokens, and bearer tokens are untrusted until validated. |
| security context → service boundary | Services must consume the authenticated principal, never a caller-supplied actor ID. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | S | REST authentication | high | mitigate | BCrypt verification, approved JWT signing/validation, expiry checks, and the API filter establish the server principal. |
| T-01-02 | E | SecurityConfig and service entry points | high | mitigate | Fixed UserRole enum, corrected LINEHAUL_DRIVER matcher, and AuthenticatedActor ownership seam prevent role/actor forgery. |
| T-01-03 | T | JSP form requests | medium | mitigate | Keep CSRF enabled on the web chain; limit CSRF disabling to stateless `/api/**`. |
| T-01-SC | Tampering | Maven JWT modules | high | mitigate | Blocking package-legitimacy checkpoint validates publisher, coordinates, and resolved dependency tree before install. |
</threat_model>
