<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| shipment service → STOMP broker | Only service-approved shipment event DTOs cross into realtime delivery. |
| application exceptions → JSP/API response | Internal failures are translated before reaching a browser or REST client. |
| authenticated client → user destination | Subscription authorization must bind the destination to the authenticated actor. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-08 | I | STOMP destination/payload | high | mitigate | Require authenticated endpoint/session, derive destination from server context, and publish DTOs without secrets or financial data. |
| T-01-09 | T | Event publication | medium | mitigate | Publish only after successful service completion through the publisher abstraction; test that failures do not emit. |
| T-01-10 | I | Error handlers | medium | mitigate | Map known failures to bounded JSP/API responses and suppress stack/error internals. |
| T-01-11 | D | WebSocket endpoint | medium | mitigate | Restrict endpoint/origin/security configuration and keep the skeleton to one publication path. |
| T-01-SC | Tampering | Maven JWT modules | high | mitigate | Retain the approved dependency-tree evidence from Plan 01-01 before full-suite verification. |
</threat_model>
